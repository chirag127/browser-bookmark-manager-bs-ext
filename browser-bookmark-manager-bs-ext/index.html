Browser Bookmark Manager

BS-EXT — take control of thousands of bookmarks with recursive sorting, duplicate detection, AI categorization, and safe recovery.

View on GitHub Privacy

Features

Recursive sorting

Multi-key sorting at every folder level, with domain-aware grouping and public-suffix handling.

Duplicate detection

Configurable normalization profiles with review before deletion.

Folder management

Create, move, merge, split by domain or category, with previews.

Bookmark bar

Explicit migration wizard — never moves data automatically.

AI categorization

Optional, opt-in, supports Gemini, OpenRouter, Groq, Mistral, custom OpenAI-compatible endpoints.

Import / Export

Netscape HTML and versioned JSON backups with restore preview.

Installation (unpacked)

  1. Download the latest release ZIP.
  2. Open chrome://extensions and enable Developer mode.
  3. Click "Load unpacked" and select the extension (or dist) folder.

Privacy

Bookmarks stay on your device. AI features are opt-in and require your own API key. No analytics or telemetry by default.
