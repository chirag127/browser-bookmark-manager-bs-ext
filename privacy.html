Privacy Policy

Last updated: 2026-10-29

What stays on your device

All bookmarks are read from your browser's native bookmark store. Extension settings, metadata, search index, and recovery records are stored locally via chrome.storage.local.

AI features

AI is disabled by default. When enabled, only the data policy you select (title, host, and/or URL) is sent to the AI provider you configure, using your own API key. No data is sent without explicit action.

Web research

Optional and explicit. Fetches public page metadata only when you request it.

Analytics

No analytics or telemetry by default. No data is sold.

Credentials

API keys are stored in browser extension storage and are never committed to source or sent to analytics.

Clearing data

Use the Settings view to clear local application data and delete credentials.
